# Kit design — hérité de Botler AI Academy
*Transmis depuis le projet e-learning (repo `BerniceWorkInAI/Botler_AI_Academy`), le 24 juillet 2026.*

Ce dossier contient **le style visuel officiel de Berni**, validé écran par écran sur le
projet Botler AI Academy (aujourd'hui en pause). Le nouveau projet — le **Sales HQ**
gamifié — doit être construit exactement dans ce style.

## Contenu
- **`CHARTE.md`** — la charte "Galerie × Blueprint" : couleurs exactes, typographie,
  matières (grain, quadrillage, coins jaunes), animations, règles d'or. **À lire en
  premier, elle fait foi.**
- **`mockups/07-accueil-galerie-blueprint.html`** — LA référence vivante du style.
  En cas de doute entre le texte de la charte et cette maquette, la maquette gagne.
- **`mockups/08` à `14`** — les autres écrans validés de l'Academy (connexion, quiz
  jouable, révélation de carte, célébration, récompenses, admin). Utiles pour voir
  comment le style se décline : états, feedbacks, interactions, célébrations.

## Comment s'en servir
Ouvrir les fichiers `.html` directement dans un navigateur (aucune installation) —
ils sont interactifs : jouer le quiz (09), révéler la carte (10), simuler la montée
de niveau (11). Le contexte e-learning n'est PAS à reproduire ; c'est le **langage
visuel et les mécaniques de motivation** (quête du jour, série 🔥 avec joker, points
sur l'effort, célébrations) qui se transposent au Sales HQ.
